Yousufweiji Hall Map SOP Reference
Three critical rules
1. VISUAL POSITION FIDELITY — every seat at exact source position.
2. SUBLAYER NAMING STRICT — SECTION, SEAT, SEATDECORATION, SECTIONDECORATION, UNDERSEATDECORATION; no numbered suffixes.
3. QA NOT OPTIONAL — all checks must pass before production upload.

Forbidden in production SVG: clipPath, mask, symbol, image, use, filter, circle, ellipse, polygon. No hidden objects. No transforms on seats. Seat count and visual positions must be verified against the source.

Production gate

  1. Import source SVG and preserve original geometry.
  2. Run Auto-Fix only after reviewing the source.
  3. Run all audit checks.
  4. Compare overlay and spot-check at least 10 seats.
  5. Verify manifest and aisle gaps.
  6. Verify XML, UTF-8 and file size.
  7. Run destination constructor staging test.
  8. Obtain lead sign-off.

Production Build Help

Secure SVG importer

The importer strips XML DTD declarations, safely expands simple internal entities, blocks external entity loading, removes scripts/foreignObject, and sanitizes unsafe resource references before rendering.

Why the renderer is robust

This build imports normalized SVG nodes directly into the live HTML document DOM and never accesses unsupported CSS interfaces on isolated XML nodes.

Production philosophy

Source geometry is preserved on import. Every destructive operation creates a snapshot and can be undone or redone. Export strictly gates against failing files and never pretends non-compliant maps are production-ready.

Round→Square conversion

Handles <circle>, <ellipse>, <path> arcs (relaxed full-circle check), near-circular <rect> (rx ≥ w/2 or ry ≥ h/2), and polygon approximations (≥12 points within tolerance of a circle). Expands <use>/<symbol> before reshape. Bakes transform translate/rotate/scale into coordinates. Preserves exact center pixel positions.
